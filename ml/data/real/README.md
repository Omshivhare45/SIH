# Real dataset drop-in location

Place a real historical train-delay dataset **here** as `train_delays.csv` and the
training pipeline (`python -m ml.train`) will automatically prefer it over the
synthetic demo data.

> Current status: this folder is empty — the repository does NOT include real
> historical delay data. Until a real file is added, the pipeline trains on the
> clearly-labelled synthetic demo data generated by `ml/synthetic_data.py`.

## Expected CSV schema

One row per (journey, station). Required columns (names are exact):

| column | type | description |
|---------------|--------|------------------|
| `journey_date` | date  | ISO date of the journey, e.g. `2026-09-11` |
| `train_number` | str   | Indian Railways train number, e.g. `22436` |
| `train_type`   | str   | e.g. `Vande Bharat`, `Rajdhani`, `Superfast` (optional) |
| `season`       | str   | `winter` / `summer` / `monsoon` / `post_monsoon` (optional) |
| `day_of_week`  | int   | 0=Mon..6=Sun (optional) |
| `is_weekend`   | int   | 0/1 (optional) |
| `month`        | int   | 1..12 (optional) |
| `station_code` | str   | station code of the CURRENT observation point |
| `station_index`| int   | 0-based position of the station on the route |
| `total_stops`  | int   | number of stations on the route |
| `stops_remaining` | int | stations left after the current one |
| `distance_km`  | float | distance from origin at current station |
| `total_distance_km` | float | full route distance |
| `remaining_distance_km` | float | total - distance_km |
| `distance_to_next_km` | float | distance to the next stop |
| `progress_ratio` | float | distance_km / total_distance_km |
| `scheduled_departure_hour` | float | scheduled origin departure as hour-of-day |
| `scheduled_arrival_minutes` | float | scheduled arrival at current station, minutes-of-day |
| `cumulative_halt_minutes` | float | sum of scheduled halts before current station |
| `halt_minutes` | float | scheduled halt at current station |
| `delay_current_minutes` | float | **feature** — observed delay at current station |
| `current_speed_kmh` | float | observed running speed |
| `delay_next_minutes` | float | **target** — actual delay at the NEXT station |

Columns marked *optional* are inferred when missing. `delay_next_minutes` is the
only strictly required target; missing optional columns are tolerated (the
preprocessor declares them as NA).

## Where to obtain real data (suggestions, not shipped)

- NTES / CRIS APIs (railapi, etc.) with the appropriate licensing.
- Public Kaggle datasets on Indian Railways train performance / delay.
- IRCTC / station-of-origin running-time data published by zones.

Add a short `PROVENANCE.txt` (source, licence, date range, row count) next to the
CSV so the audit trail is clear.
